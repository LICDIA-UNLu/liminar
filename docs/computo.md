# Cómputo

Los modelos se entrenaron y evaluaron en la supercomputadora Clementina XXI.

- **GPU:** Intel Data Center GPU Max 1550, con dos tiles de 64 GB cada una. El sistema expone cada tile como una GPU.
- **Nodo:** 4 placas, 8 tiles. Cada entrenamiento ocupa un nodo entero.
- **Unidad:** las horas de GPU se informan en horas de tile; una hora de nodo equivale a 8 horas de GPU.
